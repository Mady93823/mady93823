<br/>

**[`multi-service-pro`](https://github.com/Mady93823/multi-service-pro)** — my largest project. A Laravel + Inertia + React service-management platform: role-based permissions, media library, PDF and CSV export, Leaflet map views, Recharts dashboards, S3 storage and realtime channels over Laravel Reverb. Typed end to end, tested with Pest, static-analysed with Larastan, SSR build via Vite.

**[`insta-schedule-bot`](https://github.com/Mady93823/insta-schedule-bot)** *(Reelforge)* — self-hosted content pipeline. Feed it one long video, get vertical clips with a burned-in watermark, then let the scheduler drip them onto Instagram on a queue.

**[`walletbot`](https://github.com/Mady93823/walletbot)** — TypeScript Telegram wallet bot on Telegraf. Prisma + PostgreSQL, Express API, `ethers` for on-chain calls, Zod validation, bcrypt, rate limiting and Winston logging.

**[`credit-card-fraud`](https://github.com/Mady93823/credit-card-fraud)** — fraud detection on heavily imbalanced transaction data. scikit-learn + pandas + SMOTE via imbalanced-learn, served behind a small Flask app.

**[`attend`](https://github.com/Mady93823/attend)** — Laravel + Breeze attendance system. Blade UI, Spatie role permissions, Excel export and PDF reports.

**[`Smart-FTP`](https://github.com/Mady93823/Smart-FTP)** — a VS Code extension: FTP sync without leaving the editor. TypeScript, `basic-ftp`, bundled with esbuild.
